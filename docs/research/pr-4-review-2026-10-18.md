# PR #4 review and fixes

Reviewed Firas F. Khabour's three commits from `3286f489881b9fbc5bb2fc2bca7dd064835b1a4c` to `6dce5e9b5bc89c9245caae863273c5a6dbc1c51f`. Separate read-only reviewers examined repository standards and the PR's stated behavior. The lead reproduced findings and applied fixes on top, preserving the original commits and credit.

## Standards

- **P1, wrong line targeted after a pending insertion.** Removing an earlier transient blank changed indices before a click's rendered index was consumed. Deleting the displayed second line could delete the third instead. Pending-row cleanup now remaps the target index for editing, deleting and inserting below a row. Leaving a poem discards its own transient row without modifying the next poem.
- **P2, line metadata did not follow its line.** Insert/delete now shifts 1-based choices and stored suggestions, removes metadata for deleted rows, and restores text plus metadata together on undo. In-flight line conversations are invalidated when rows move.

Both were violations of the authored-text/edit-scope preservation requirement. No style-only refactors were requested.

## Specification

- **P2, word alternatives reused another poem's context.** Cache keys now include the full poem request context, including identity, text, mode, meter, revision and selection epoch. A late reply for an old key cannot populate the currently selected context.
- **P2, free-verse replacement checking ignored `--poem`.** Explicit rhyme-repeat filtering now runs in free and classical modes. A metrically sound candidate rejected for repetition is no longer called metrically broken in the detailed verdict.
- **P2, later verses were treated as openings.** The replacement CLI now honors `--line` when choosing first-verse-only تصريع forms. Absent a line number, standalone candidate behavior is retained.

## Additional lead checks

- **P2, physical line numbers changed around blank rows.** The replacement CLI now counts file rows before filtering empty text, so `--line` excludes the actual replacement row.
- **P2, supplied vowels were silently relocated.** Removed the new unconditional word-final ya/kasra correction in both runtimes. A possibly mistyped vowel must be clarified rather than moved merely to improve a scan.
- Clarified the strict repeated-rhyme spelling filter. Al-Hashimi's [عيوب القافية](https://www.safahat.org/books/50259706/2.5/) distinguishes a repeated word's meaning and interval; the source map now links that chapter and states that the editing filter does not resolve those conditions. Displayed warnings say possible إيطاء rather than asserting a complete semantic judgment. Updated stale maintainer/report descriptions after removal of the binary arithmetic checker.
