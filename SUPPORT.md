# Support

Report installation problems, scanner issues, and documentation errors through [GitHub Issues](https://github.com/WellDunDun/arabic-poetry/issues). Responses depend on maintainer availability. See the [README credits](README.md#credits) for the original skill and Firas F. Khabour's scanner, Diwan and exporter contributions.

Include your agent or browser, the installed plugin version, the action you tried, and the error message. For a poetry example, include only a short passage you have permission to share publicly. Explain the intended reading and what you expected. Do not include unpublished work, secrets, private logs, or personal information.

Meter results depend on pronunciation and implemented coverage. A nearest match is not proof of a licensed form, literary quality, or historical attribution. See the [scanner coverage notes](skills/arabic-poetry/references/SCANNER-SOURCES.md).

For a ChatGPT directory installation, package updates come through newly published directory versions. GitHub commits alone do not update that listing. Repository marketplace installations use their host's separate update controls. See [installation and updates](INSTALL.md).

The optional local scanner needs Python. Diwan and exports depend on the capabilities available in your environment; installing a plugin does not grant arbitrary local file access to a browser chat. See [privacy](PRIVACY.md) for storage and third-party requests.
