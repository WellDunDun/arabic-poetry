# الزحافات والعلل

## الزحاف (changes in the second letter of a sabab; mostly optional, may vary from line to line)

### Single zihafat (الزحاف المفرد)
| الاسم | ما يحدث | أمثلة |
|---|---|---|
| الإضمار | تسكين الثاني المتحرك | متَفاعلن → متْفاعلن (− − ب −) |
| الخبن | حذف الثاني الساكن | مستفعلن → متفعلن (ب − ب −)، فاعلن → فعِلن، فاعلاتن → فعِلاتن، مفعولاتُ → معولاتُ |
| الوقص | حذف الثاني المتحرك | متَفاعلن → مفاعلن (ب − ب −) |
| الطيّ | حذف الرابع الساكن | مستفعلن → مستعلن (− ب ب − = مفتعلن)، مفعولاتُ → مفعلاتُ (فاعلاتُ) |
| العصب | تسكين الخامس المتحرك | مفاعَلَتن → مفاعلْتن (ب − − − = مفاعيلن) |
| القبض | حذف الخامس الساكن | فعولن → فعولُ (ب − ب)، مفاعيلن → مفاعلن |
| العقل | حذف الخامس المتحرك | مفاعَلَتن → مفاعَتن (ب − ب −) |
| الكفّ | حذف السابع الساكن | مفاعيلن → مفاعيلُ، فاعلاتن → فاعلاتُ |

### Double zihafat (الزحاف المزدوج)
| الاسم | = | مثال |
|---|---|---|
| الخبل | خبن + طي | مستفعلن → متَعِلن (ب ب ب − = فعِلَتن) |
| الخزل | إضمار + طي | متفاعلن → متْفَعِلن (− ب ب −) |
| الشكل | خبن + كف | فاعلاتن → فعِلاتُ (ب ب − ب) |
| النقص | عصب + كف | مفاعلتن → مفاعلْتُ (ب − − ب) |

Zihaf in the arud/darb that is not "lazim" may vary; a zihaf that the poet
commits to in the darb of the first line (e.g. القبض في ضرب الطويل) becomes the
poem's darb form and must stay.

## العلل (changes in the arud/darb, usually binding across the poem)

### علل الزيادة
| الاسم | ما يحدث | مثال |
|---|---|---|
| الترفيل | زيادة سبب خفيف على ما آخره وتد مجموع | متفاعلن → متفاعلاتن |
| التذييل | زيادة ساكن على ما آخره وتد مجموع | متفاعلن → متفاعلانْ، مستفعلن → مستفعلانْ |
| التسبيغ | زيادة ساكن على ما آخره سبب خفيف | فاعلاتن → فاعلاتانْ |

### علل النقص
| الاسم | ما يحدث | مثال |
|---|---|---|
| الحذف | إسقاط السبب الخفيف من آخر التفعيلة | فعولن → فعو، فاعلاتن → فاعلا (فاعلن)، مفاعيلن → مفاعي (فعولن) |
| القطف | حذف + عصب | مفاعلتن → مفاعلْ (فعولن) |
| القصر | حذف ساكن السبب الخفيف وتسكين ما قبله | فعولن → فعولْ، فاعلاتن → فاعلانْ |
| القطع | حذف ساكن الوتد المجموع وتسكين ما قبله | مستفعلن → مستفعلْ (مفعولن)، متفاعلن → متفاعلْ (فعِلاتن)، فاعلن → فاعلْ (فعْلن) |
| البتر | حذف + قطع | فعولن → فعْ، فاعلاتن → فاعلْ (فعْلن) |
| الحذذ | حذف الوتد المجموع من آخر التفعيلة | متفاعلن → متفا (فعِلن) |
| الصلم | حذف الوتد المفروق | مفعولاتُ → مفعو (فعْلن) |
| الكشف | حذف آخر الوتد المفروق | مفعولاتُ → مفعولا (مفعولن)؛ with طي → فاعلن (السريع) |
| الوقف | تسكين آخر الوتد المفروق | مفعولاتُ → مفعولاتْ |
| التشعيث | حذف أول الوتد المجموع أو ثانيه | فاعلاتن → فالاتن (مفعولن) — زحاف يجري مجرى العلة، شائع في ضرب الخفيف |

## Practical notes for diagnosis

- A change above is locally permissible only if licensed in that meter and
  position. Check the whole line, its reading and applicable ending pair
  before calling it sound. The scanner encodes selected permissions, not all
  rules; consult [sources and coverage](SCANNER-SOURCES.md) for uncertain cases.
- A missing/extra letter inside a watad (ب −) in the hashw is a كسر.
- Common real-world breaks: a stray conjunction (و/ف) adding a moving letter;
  dropping a needed tanwin; reading hamzat wasl as qat'; an unintended long
  vowel (ما/لا/في) where a short one is needed.
