# Arabic Poetry 0.3.1

Draft release notes. This version is awaiting review in [PR #11](https://github.com/WellDunDun/arabic-poetry/pull/11) and [PR #12](https://github.com/WellDunDun/arabic-poetry/pull/12). It is not yet available through the default installation.

## English

### Word suggestions without the chat handoff

Open a word's menu in Diwan and choose its replacement option. Diwan requests suggestions automatically through a supported host connection or an installed, signed-in Claude Code or Codex client. Your poem changes only when you accept a replacement.

Requests through an installed client use its existing login and normal model usage allowance. They run separately from your open chat and send the relevant poem context to that client's model service. Manual chat mode remains available.

### Updates that wait for your edits

An open shared-file Diwan can pick up compatible plugin updates after your plugin manager installs them. If you are editing, saving, waiting for suggestions or resolving a conflict, the page waits before refreshing. An update never forces a save or discards your draft.

Your poem stays in the same file, with its saved revision history. The editor keeps its address. If the replacement cannot run, Diwan returns to the working version. Conflicting drafts remain visible with recovery controls.

### Upgrading an existing editor

1. Save your current edits. If a conflict prevents saving, download your draft before reopening the editor.
2. Update Arabic Poetry using your plugin manager. Follow the [installation and update guide](../../INSTALL.md) for your agent.
3. Start a fresh agent session if required, then ask it to reopen the same poem file. An editor launched by an older version needs this one-time reopen to enable safe updates.

After that, compatible installed updates can reach the open editor automatically. Diwan does not download releases or change your plugin manager's update settings.

Copy this into your agent after the release is available:

```text
Update my installed Arabic Poetry plugin to version 0.3.1 or later using its existing repository connection. Preserve my installation settings and poem files. Before reopening an older Diwan session, help me save my edits or download any conflicting draft. Reopen the same poem file without recreating it, and verify the installed version. If this installation cannot update automatically, explain the supported update method.
```

Automatic editor updates currently support compatible versions in Claude Code's user installation or Codex's versioned plugin cache. Standalone skills, ZIP uploads, account-only browser installations and incompatible updates require reopening. This release does not add a public ChatGPT directory listing or a ChatGPT editor extension. Local shared-file saving supports macOS and Linux.

## العربية

هذه مسودة ملاحظات الإصدار. لم يُنشر الإصدار بعد، ولن يصل عبر مسار التثبيت الافتراضي قبل اكتمال المراجعة.

### اقتراح بدائل الكلمات مباشرة

افتح قائمة الكلمة في ديوان واختر اقتراح البدائل. يطلب ديوان الاقتراحات تلقائيًا عبر اتصال مدعوم داخل بيئة الوكيل، أو عبر عميل Claude Code أو Codex مثبّت ومسجّل الدخول. لا تتغيّر القصيدة إلا عندما تختار بديلًا.

تستخدم طلبات العميل المثبّت تسجيل الدخول الحالي وتُحتسب ضمن استخدامك المعتاد للنموذج. تعمل هذه الطلبات بشكل منفصل عن محادثتك المفتوحة، وتُرسل سياق القصيدة اللازم إلى خدمة النموذج التي يستخدمها العميل. يظل وضع المحادثة اليدوي متاحًا.

### تحديثات تنتظر انتهاء التحرير

يمكن لديوان المفتوح على ملف قصيدة مشترك التقاط تحديثات الإضافة المتوافقة بعد أن يثبّتها مدير الإضافات. تنتظر الصفحة قبل إعادة التحميل إذا كنت تحرّر النص أو تحفظه، أو تنتظر اقتراحًا، أو تعالج تعارضًا. لا يفرض التحديث حفظ المسودة ولا يتجاهلها.

تبقى القصيدة في الملف نفسه مع سجل النسخ المحفوظة، ويحتفظ المحرر بعنوانه. إذا تعذّر تشغيل النسخة الجديدة، يعود ديوان إلى النسخة التي كانت تعمل. وتبقى المسودات المتعارضة ظاهرة مع خيارات استعادتها.

### تحديث محرر مفتوح من إصدار سابق

1. احفظ تعديلاتك الحالية. إذا منعك تعارض من الحفظ، نزّل مسودتك قبل إعادة فتح المحرر.
2. حدّث إضافة الشعر العربي عبر مدير الإضافات. اتبع [دليل التثبيت والتحديث](../../INSTALL.md) للوكيل الذي تستخدمه.
3. ابدأ جلسة جديدة مع الوكيل إذا لزم الأمر، ثم اطلب منه إعادة فتح ملف القصيدة نفسه. يحتاج المحرر الذي شغّله إصدار قديم إلى إعادة الفتح مرة واحدة لتفعيل التحديث الآمن.

بعد ذلك، يمكن للتحديثات المتوافقة المثبّتة الوصول إلى المحرر المفتوح تلقائيًا. لا ينزّل ديوان الإصدارات ولا يغيّر إعدادات التحديث في مدير الإضافات.

انسخ هذا الطلب إلى وكيلك بعد نشر الإصدار:

```text
حدّث إضافة الشعر العربي المثبّتة لدي إلى الإصدار 0.3.1 أو أحدث عبر اتصالها الحالي بالمستودع. حافظ على إعدادات التثبيت وملفات قصائدي. قبل إعادة فتح جلسة ديوان قديمة، ساعدني على حفظ تعديلاتي أو تنزيل أي مسودة متعارضة. أعد فتح ملف القصيدة نفسه دون إعادة إنشائه، وتحقّق من الإصدار المثبّت. إذا كانت طريقة التثبيت هذه لا تدعم التحديث التلقائي، فوضّح طريقة التحديث المدعومة.
```

تدعم تحديثات المحرر التلقائية حاليًا الإصدارات المتوافقة في تثبيت Claude Code الخاص بالمستخدم، أو في ذاكرة إضافات Codex التي تحتفظ بمجلد لكل إصدار. تتطلب المهارات المستقلة وملفات ZIP والتثبيتات المرتبطة بحساب المتصفح فقط والتحديثات غير المتوافقة إعادة فتح المحرر. لا يضيف هذا الإصدار إدراجًا في دليل ChatGPT العام أو امتدادًا لمحرر داخل ChatGPT. يدعم حفظ الملف المحلي المشترك macOS وLinux.
